## 世系图布局重构（js/layout.js）

用户反馈「构图隔得太远」，要求：早期世代靠拢、代间不碰撞、人物向下竖线加长、无子嗣者可贴到分支线上方。

改动：
- 横向：把原来的「矩形块铺排」换成「轮廓贴合 + 矩形占位」混合（`packSubtree` 记录每棵子树在各层的最左/最右轮廓，兄弟分支按轮廓咬合，再由 `PACK_TIGHTNESS` 保留松量）。总览宽度 4250 → 1589，同一缩放下可见更多世代，长横线不再横穿空白。
- 列距 `NODE.colGap` 46 → 24；根节点间距由 1 个 NODE_STEP 降到 1.3 倍轮廓间距。
- 配偶不再固定占 `NODE_STEP`，改为就近找空位（`slotFree` 逐个 slot 试探，再换另一侧）。
- 纵向：`ROW_PITCH` 固定 208 改为按结构决定（`STACK`：bus 62 / busLeaf 56 / chain 56），靠前世代再收紧（`topTighten` 8，12 代内淡出）；人物下沿到分支线 `stem` 22 → 33。
- 无子嗣者卡片上浮 `leafLift` 12，且不再为后代预留列宽（轮廓天然处理）。

验证脚本（临时，已删）：检查 5 套谱系无卡片重叠、无退化路径。结果：minDx 148、minDy 12、overlaps 0。

归档：`.workbuddy/preview/` 下有 compare-zoom.png（同缩放前后对比）、fin-all.png、fin-femp.png、layout.before.js.txt（旧版布局代码）。

注意：`.workbuddy` 里别放 node_modules；临时用 playwright-core 截图时要在项目外的目录安装（曾误装到根目录，已清理 package.json / node_modules / package-lock.json）。

## 第二轮：代高统一 + 单传直线 + 兄弟等距（js/layout.js 重写核心排布）

用户要求：① 每一代高度必须相同；② 单对单关系不能折、必须一条直线；③ 同一人的多个子女在深后代不挤的前提下尽量平均分配宽度。

改动：
- 删掉 `STACK` / `PACK_TIGHTNESS` / `packSubtree` 那套「轮廓咬合 + 逐代变高」，换成 `ROW = { pitch: 200, stem: 33, dropMin: 19 }`：行高 `NODE.top + rowIndex * 200`，全员同 y（同时删掉 `leafLift` 的上浮）。
- `buildShape` 递归返回 `{ offsets, left[], right[] }`：独子 offset 恒 0（父→子一条竖线）；多子共用一个 `groupStep`，取「任意两棵子树 × 任意一层」的最紧约束 `(right_i[d] + left_j[d] + colGap) / (j-i)` 的最大值，兄弟因此等距且任意一层不挤。
- 连线几何：只有「血统主亲」向下落到总线；配偶改为卡片中部一条 `tie` 婚配线（新增 `kind: 'tie'`，样式 `.link-path.tie`）。原来配偶也垂到总线，会让子女看起来像从母亲那里垂下来。
- 根节点也走同一套 groupStep，不再特殊处理。

校验：`node .tmp/check.mjs`（临时，已删）对 5 套谱系检查 pitch 全为 200、同代无重叠、独子 dx=0 且无横段、兄弟间距组内一致，全部通过。总览 1464×6884（旧 1589×6651，宽度略收、高度略增）。

归档：`.workbuddy/preview/` 下 all-new.png、compare-femp.png、zhou-couple-detail.png、zhou-ten-sons.png、all-top-detail.png、xia-trunk.png、layout.prev.js.txt（本轮改前的版本，可回滚）。
